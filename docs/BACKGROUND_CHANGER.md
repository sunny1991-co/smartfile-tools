# Background changer phase 1

Local Web Worker and OffscreenCanvas, 60-second watchdog and cancellation. Replaces edge-connected pixels matching a user-selected plain color; no AI or person detection. Transparent PNG cutouts can be placed over solid colors, transparent output or user-supplied scene photos (e.g. car). Subject scale and alignment, preview of generated PNG. Input 25 MB/24 MP per file, output long side <=1600 px. No built-in background photos, no automatic shadow/lighting correction, no complex scene removal. Tests independently check exact synthetic pixels and speed; actual portraits and low-memory devices require review. Future automatic segmentation: review model license, size, runtime security and representative portrait quality, load only on request. Do not enable a paid API or upload images.
