# Visual design gate

Original inline SVG icons, one distinct shape per tool; three static categories in both languages. No icon library, font downloads, animation or extra JavaScript. Mobile two-column cards, readable Hindi and English labels, focus outlines and text labels independent of color. Tool pages reuse the matching icon. Existing URLs, search verification and PDF processing preserved. CI checks unique icons, category navigation, horizontal overflow at 320–1280 px and existing performance budgets. Visual comparison to competitors is subjective; actual mobile user review remains necessary. Screenshots are generated by the browser test.
